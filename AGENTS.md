# Rust development

Apply the relevant guidance from [Rust Skills](https://github.com/leonardomso/rust-skills) and [Microsoft's Pragmatic Rust Guidelines](https://microsoft.github.io/rust-guidelines/agents/all.txt) when writing or reviewing Rust in this repository. Interpret the guidance in the context of the affected crate, including `no_std` and the firmware's interrupt and memory constraints.

Use `curl` or `xh` for simple HTTP probes. Prefer Rust for more complex or reusable tooling.
